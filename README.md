# Manish Mandal - Engineering & Open-Source Projects

Welcome to my open-source engineering and development workspace.

This repository is focused on building and sharing practical tools, experiments,
and resources that can help engineers and developers solve real-world problems.

## 🚀 Project Goals

The goal of this project is to create accessible, reusable, and well-documented
engineering tools while learning from and contributing to the open-source community.

Areas of interest include:

- Engineering calculations
- Mechanical design tools
- GD&T and tolerance analysis
- Engineering automation
- Technical documentation
- Web-based engineering utilities
- AI-assisted engineering workflows

## 💡 Planned Engineering Tools

Some tools being considered for development include:

### Tolerance Stack Calculator
A web-based utility for performing dimensional tolerance-stack analysis.

Potential capabilities:
- Worst-case tolerance analysis
- RSS statistical analysis
- Bilateral and unilateral tolerances
- 1D tolerance stacks

### GD&T Utilities
Simple tools and reference implementations for common GD&T calculations.

Potential capabilities:
- MMC bonus tolerance
- Virtual condition
- Positional tolerance calculations
- Fit and clearance calculations

### Engineering Unit Converter
Conversion tools for commonly used mechanical-engineering units.
